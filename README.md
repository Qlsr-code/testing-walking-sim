# Walking Simulator: Тени Старого Дома

Текстовый walking-simulator / интерактивная история на русском языке.
Исследуй старый дом: свободный ввод, инвентарь, скрытые находки и несколько концовок.

(Это личный «учебный» и тестовый материал для отработки.)

## Запуск

Нужен **Python 3.10+** (сторонние зависимости не требуются).

```bash
python main.py
```

Альтернатива — напрямую актуальная версия:

```bash
python main2_grok_v1.6.py
```

## Управление

| Ввод | Действие |
|------|----------|
| `1`, `2`, `3`… | Крупные действия из меню |
| слова из описания | осмотр, взять, использовать, слушать… |
| `инвентарь` / `i` | список вещей (сцена не сбрасывается) |
| `осмотреться` | снова описание места |
| `помощь` / `?` | подсказка по командам |

Не всё лежит на виду. Часть находок — просто мусор.
